# `apps/web` — React 19 + TypeScript 工作台

## 技术栈

- **构建与框架**：Vite 6 + React 19 + TypeScript
- **样式与组件**：Tailwind CSS v4 + `shadcn/ui` + [src/styles/tokens.css](src/styles/tokens.css)（承接 V1“时间地图”Material 3 浅/深色令牌）
- **状态与契约**：TanStack Query v5 + Zustand + `openapi-typescript` / `openapi-fetch`

## 已保留的 V1 视觉资产

- `public/brand-logo.png` — 品牌 Logo
- `public/favicon.png` — 浏览器图标
- `src/styles/tokens.css` — 浅/深色品牌语义令牌与日历时间线样式

设计规范与 V1→V2 页面精简映射见 [docs/design-system-v2.md](../../docs/design-system-v2.md)。
