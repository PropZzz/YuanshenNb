# Web 日历与选择机制完善

**Goal:** 沿用现有 Web 视觉，统一日期与视图状态，补齐月历完整日程入口和键盘时间选择；不修改 Android、服务端或接口。

**Architecture:** 日期、视图和甘特比例以 URL 为单一来源。复用 Radix 日期弹层，抽出支持年月切换和键盘操作的日期网格。月历保留概览并增加所选日期的完整列表；时间地图的点击和方向键共用 15 分钟选择状态，新建仍需明确保存。

**Tech Stack:** 现有 React、TypeScript、React Router、Radix、Vitest、Playwright，不增加依赖。

- [x] 日期/视图持久、非法日期、跨月、详情链接和历史导航回归。
- [x] 日期弹层的年月选择、方向键、确认/取消和原时间保留回归。
- [x] 月历完整列表、更多入口、周视图高亮和 15 分钟键盘选择。
- [x] 全站测试、类型与构建；桌面/手机焦点、日期切换与无溢出检查并打开预览。

浏览器布局回归使用明确的 API 测试夹具，真实服务不可用时如实记录。不自动提交、推送或部署。

## 最终实现与验收（2026-11-23）

- 日期、日/周/月/甘特视图、甘特尺度保存至 URL，刷新和浏览器前进/后退可恢复；选择事件和打开编辑时带上事件真实日期。关闭新建清理旧 time 参数，避免下一次误用旧时间点。
- 统一日期弹层支持年月选择、翻月、今天、方向键、Home/End、PageUp/PageDown（Shift 按年）、显式确认和取消；原始时分不丢失。今天使用账号时区；弹层按窗口重新定位并支持短窗口内部滚动。非法或无法投影的日期不会导致页面崩溃。
- 月历显示所选日期全部日程，超过三项的入口切到对应日视图；日/周地图明确区分今天与选中日期。空白时间网格的鼠标提示和键盘共用 15 分钟刻度，回车只打开草稿，仍需保存才写入服务端。
- 修正旧单测依赖系统当天的问题：日历查询绑定夹具日期，救援测试只固定 Date、不冻结事件定时器；保留原业务断言。
